카포 CAPO — 개인정보 처리방침

최종 수정 / Last updated: 2026-07-31

요약: 당신의 음악은 어떤 경우에도 서버로 전송되지 않습니다. 계정도 로그인도 없습니다. 수집하는 것은 선택 동의한 경우의 익명 사용 통계뿐입니다.

1. 수집하는 정보 — 사용 통계 (동의한 경우에만)

  • 익명 기기 식별자(무작위 생성), 이벤트 이름과 발생 시각, 앱·OS 버전
  • 이벤트는 넷뿐입니다: 앱 실행 · 키 변경 완료 · 형제 앱 링크 탭 · 동의 응답 — 전부 횟수만
  • 첫 실행 때 동의를 묻고, '보내지 않기'를 고르면 아무것도 수집하지 않습니다

2. 수집하지 않는 것

  • 오디오 파일·변환 결과 — 절대 수집하지 않습니다. 키 감지와 키 변경은 전부 기기 안에서 실행됩니다.
  • 파일 이름·내용·연락처·위치도 수집하지 않습니다. 광고 식별자·추적 기술을 쓰지 않습니다.
  • 네트워크는 한 갈래뿐입니다: 동의한 경우의 위 통계 전송. 동의하지 않으면 네트워크 통신 자체가 없습니다.

3. 보관·위탁

  • 사용 통계는 Supabase, Inc. 서버(호주 시드니 리전, ap-southeast-2)에 저장되며 최대 24개월 보관 후 파기합니다.
  • 앱은 전부 무료입니다 — 결제·구독·계정이 없습니다.

English

Your music never leaves your device. No account, no sign-in. The app is completely free — no purchases, no subscriptions. Key detection and key shifting run entirely on-device. The only data collected is opt-in anonymous usage statistics: a random device ID and four event counts (launch, key change finished, sibling-app link tap, consent choice). Audio, file names, and contents are never collected. One network path only: the statistics above, sent if you consent (stored with Supabase, Sydney region, kept up to 24 months). Decline consent at first launch and the app makes no network requests at all.
