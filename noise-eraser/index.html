잡음 지우개 — 개인정보 처리방침

최종 수정 / Last updated: 2026-07-29

요약: 당신의 녹음은 어떤 경우에도 서버로 전송되지 않습니다. 계정도 로그인도 없습니다. 수집하는 것은 선택 동의한 경우의 익명 사용 통계뿐입니다.

1. 수집하는 정보 — 사용 통계 (동의한 경우에만)

  • 익명 기기 식별자(무작위 생성), 이벤트 이름과 발생 시각, 앱·OS 버전
  • 이벤트는 넷뿐입니다: 앱 실행 · 처리 완료 · 무료 한도(10분) 도달 · 안내 링크 탭 — 전부 횟수만
  • 첫 실행 때 동의를 묻고, '보내지 않기'를 고르면 아무것도 수집하지 않습니다

2. 수집하지 않는 것

  • 오디오 파일·녹음·처리 결과 — 절대 수집하지 않습니다. 모든 처리는 기기 안에서 실행됩니다.
  • 파일 이름·내용·연락처·위치도 수집하지 않습니다. 광고 식별자·추적 기술을 쓰지 않습니다.
  • 네트워크는 두 갈래뿐입니다: 첫 실행 때 청소 모델(약 213MB)을 받는 것(내려받기만), 그리고 동의한 경우의 위 통계 전송.

3. 보관·위탁

  • 사용 통계는 Supabase, Inc. 서버(호주 시드니 리전, ap-southeast-2)에 저장되며 최대 24개월 보관 후 파기합니다.
  • 인앱 결제는 Apple의 App Store가 처리하며, 개발자는 익명 거래 정보 외에 접근하지 않습니다.

English

Your recordings never leave your device. No account, no sign-in. The only data collected is opt-in anonymous usage statistics: a random device ID and four event counts (launch, cleaning finished, free-limit reached, info-link tap). Audio, file names, and contents are never collected. Two network paths only: a one-time cleaning-model download (~213MB, receive-only) and, if you consent, the statistics above (stored with Supabase, Sydney region, kept up to 24 months). In-app purchases are handled by Apple. Decline consent at first launch and nothing is collected.
